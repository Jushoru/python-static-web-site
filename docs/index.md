# Генераторы статических сайтов для публикации результатов исследований

## Цель работы

Исследовать возможности генераторов статических сайтов для публикации результатов
экспериментов и освоить автоматическую сборку и публикацию сайта на MkDocs.

## Содержание отчёта

- **Ход работы:** настройка окружения, сборка сайта и публикация.
- **Исследовательское задание T1:** сравнение генераторов статических сайтов.
- **Практическое задание P3:** воспроизводимый конвейер «данные → результат → сайт».
- **Проверки и отладка:** измерения, обнаруженные ошибки и способы их устранения.
- **Выводы:** выбор инструментов и ограничения предложенного решения.

# Генераторы статических сайтов для публикации результатов исследований

## Цель работы

Исследовать возможности генераторов статических сайтов для публикации результатов
экспериментов и освоить автоматическую сборку и публикацию сайта на MkDocs.

## Содержание отчёта

- [Теория T1](theory.md): матрица 18 критериев, веса и результаты сравнения.
- [Иллюстрации и исходники](theory-scores.md): радарная диаграмма, схема отчёта и исходный текст.
- [Практика P3](practice.md): устройство эксперимента на MkDocs.
- [Пример тестовой страницы](example.md): содержимое, которое генерирует скрипт.
- [Результаты эксперимента](results.md): реальные замеры, таблицы и графики.
- [Сборка и кэширование](build.md): команды Nox, устройство кэша и измеренное ускорение.
- [Публикация и CI](deployment.md): workflow GitHub Actions, публикация на двух площадках и проверки.
- [Отладка](debugging.md): обнаруженные проблемы и способы их устранения.

## Что именно исследуется

В теоретической части T1 выполнено сравнение MkDocs, Sphinx, Pelican и Quarto.
Составлена матрица оценок, определены веса критериев и сформулированы условия выбора.
P3 — отдельный эксперимент: измерение полной сборки MkDocs для 10, 50 и 100
страниц, обработка результатов Python-скриптом и повторное использование
результатов анализа через кэш. Экспертные баллы T1 не являются замерами P3.

Контрольная строка для проверки публикации: **PYTHON-STATIC-REPORT-T1-P3**.
